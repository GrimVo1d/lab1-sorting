# ЛР1 — Алгоритмы сортировок

Лабораторная работа №1 по дисциплине «Программные технологии», вариант 5.

**Реализованы:** сортировка пузырьком, быстрая сортировка (Хоара),
сортировка слиянием. В качестве эталона использована `std::sort`.

**Структура данных:** массив объектов «Преподаватель» (ФИО,
факультет, учёное звание, учёная степень). Сравнение по полям
`факультет → ФИО → степень → звание`.


## Сборка и прогон

```bash
make plots docs
```

Цели Makefile:

- `make` — собрать `hw1` и `data_gen`;
- `make gen-data` — сгенерировать тестовые наборы в `data/`;
- `make bench` — прогон бенчмарка, результаты в `results/timings.csv`;
- `make plots` — построить графики через `plot.py`;
- `make docs` — сгенерировать HTML-документацию через Doxygen.

## Зависимости

- C++17 (`clang++` или `g++`)
- GNU Make
- Python 3 + `matplotlib` + `pandas` (для `make plots`)
- Doxygen (для `make docs`)

## Структура

```
src/             исходники C++ с doxygen-комментариями
data/            сгенерированные CSV-наборы
results/         timings.csv + plots.png
docs/html/       сгенерированная Doxygen документация
Makefile
Doxyfile
plot.py
```
